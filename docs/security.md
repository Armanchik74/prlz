# Модель безопасности

## Защищаемые данные

- имя, телефон, идентификатор пользователя;
- история избранного и бронирований;
- данные продавца и остатки;
- токены доступа, ключи шифрования, журналы безопасности.

Точная геопозиция обрабатывается в памяти для ближайшей выдачи и по умолчанию
не сохраняется.

## Основные угрозы и меры

| Угроза | Реализованная мера | До production |
|---|---|---|
| Перехват трафика | клиент готов к HTTPS, HTTP разрешён только для localhost | TLS 1.2+, HSTS, certificate monitoring |
| Кража токена | Keychain с ThisDeviceOnly, короткий access token | refresh rotation, device/session revocation |
| Утечка БД | AES-256-GCM для имени/телефона, отдельный keyed hash | KMS/HSM, регулярная ротация ключей |
| SQL injection | параметризованные запросы, Zod-валидация | SAST/DAST и внешний pentest |
| Перебор API | rate limit в Fastify и Nginx | WAF и отдельные лимиты OTP |
| Подмена наличия | изменение остатков только сервером, транзакции | seller RBAC и аудит каждой мутации |
| IDOR | ресурсы пользователя фильтруются по user_id из токена | негативные интеграционные тесты |
| Логи с ПДн | redaction заголовков и полей профиля | DLP-проверки и политика доступа |
| Supply-chain | pinned major/minor версии, отдельный non-root образ | lockfile, Dependabot, подпись образов и SBOM |

## Обязательные эксплуатационные процедуры

1. Модель угроз ИСПДн и определение уровня защищённости.
2. Матрица доступа, MFA для администраторов, quarterly access review.
3. Резервные копии, проверка восстановления не реже раза в квартал.
4. План реагирования: обнаружение, изоляция, сохранение артефактов, уведомление
   Роскомнадзора и субъектов в предусмотренных законом случаях.
5. Удаление/обезличивание по срокам хранения, фиксация выполнения запросов
   субъектов.
6. Внешний pentest перед запуском и после существенных изменений.

## Секреты

Файл .env не коммитится. В production ключи поступают из менеджера секретов.
Ключ шифрования ПДн и HMAC-ключ должны быть независимыми. Ротация выполняется
через версионирование ciphertext и фоновое перешифрование.
