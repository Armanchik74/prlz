# «Есть рядом» — городской маркетплейс наличия товаров

Рабочий монорепозиторий мобильной платформы, собранный из прототипов
`marketplace-customer.html` и `marketplace-seller.html`.

Первый релиз — приложение покупателя для iOS. Приложение продавца будет
отдельным клиентом, но использует ту же предметную модель, API, учётные записи
организаций и инфраструктуру.

## Что уже реализовано

- нативный SwiftUI-клиент покупателя: каталог, поиск и сравнение предложений,
  карта, карточки магазина и товара, избранное, бронирования и профиль;
- REST API на TypeScript/Fastify с PostgreSQL/PostGIS;
- единая схема данных для покупателей, продавцов, магазинов, предложений,
  остатков, избранного и броней;
- локальный запуск через Docker Compose, health checks и reverse proxy;
- миграция и демо-данные из HTML-прототипа;
- базовые меры безопасности, журналирование событий и документация по
  персональным данным;
- CI для API и проверка iOS-проекта на macOS runner.

## Быстрый запуск backend

1. Скопируйте `.env.example` в `.env` и замените все значения с `change-me`.
2. Запустите `docker compose up --build`.
3. API будет доступен на `http://localhost:8080/api/v1`, health check —
   `http://localhost:8080/health`.

Демо-данные загружаются миграцией при первом создании БД. Для локальной
разработки авторизация допускает заголовок `X-Debug-User-Id`; при
`APP_ENV=production` этот режим заблокирован.

## Запуск iOS

Требования: Xcode 16+, iOS 17+, XcodeGen.

```bash
cd apps/customer-ios
xcodegen generate
open CustomerApp.xcodeproj
```

По умолчанию симулятор обращается к `http://127.0.0.1:8080/api/v1`. Для
физического устройства укажите HTTPS URL стенда в `API_BASE_URL` build setting.
Перед App Store-сборкой добавьте утверждённый логотип в AppIcon asset set.

## Границы текущего этапа

Это рабочий фундамент MVP, а не разрешение на запуск с реальными персональными
данными. До публикации нужны: российский SMS-провайдер, российский хостинг,
договоры поручения обработки, утверждённые тексты оферты/политики/согласий,
уведомление Роскомнадзора, внешний pentest, мониторинг и App Store-подпись.
Чек-лист находится в [`docs/compliance-ru.md`](docs/compliance-ru.md).

## Структура

```text
apps/customer-ios/   iOS-приложение покупателя
services/api/        API и миграции PostgreSQL
infra/               reverse proxy и эксплуатационные файлы
docs/                архитектура, безопасность, соответствие требованиям
```

Исходные HTML-прототипы остаются в корне GitHub-репозитория как визуальный и
функциональный эталон.
